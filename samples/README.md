# 합성 경매 PDF

`synthetic-auction.pdf`는 실제 물건이나 개인정보가 없는 인식 테스트용 문서입니다. 다음 사실만 적혀 있습니다.

| 항목 | 예상 인식값 |
|---|---|
| 법원 | SEOUL |
| 사건번호 | 2026-TEST-42 |
| 물건번호 | 1 |
| 매각기일 | 2030-10-22 |
| 감정가 | 200,000,000원 |
| 최저가 | 140,000,000원 |

예상 낙찰가·가상 입찰가·시세·비용·목표 이익은 문서에 없으며 AI가 채우면 안 됩니다. 앱의 ‘실제 PDF 인식 테스트’ 버튼은 별도의 합성 문서를 내부 생성하며 파일을 직접 선택하지 않아도 됩니다.

이 파일은 `tools/live_gemini_check.py`의 `synthetic_pdf()`로 생성했습니다. 로컬에서 정상 PDF 구조와 텍스트 추출을 확인했으며, 실제 Gemini 인식 성공을 의미하지 않습니다.
