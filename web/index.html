    CONNECTION
    AI 연결 설정
    수동 입력과 기록 조회에는 API 키가 필요하지 않습니다.
    
    
    Gemini 연결
    기존에 성공했던 gemini-flash-lite-latest를 기본 모델로 사용합니다.
    키는 메모리에서만 사용합니다. 새로고침하거나 창을 닫으면 지워지며 백업·GitHub에 포함하지 않습니다. Apps Script에 등록했던 키는 자동으로 가져올 수 없습니다.
    키를 입력한 브라우저에서 Google API로 직접 요청합니다. API 키의 HTTP 리퍼러 제한을 사용한다면 이 앱을 연 주소를 허용해야 합니다. 자동 재시도는 하지 않습니다.
    
    
    기록 보관과 백업
    기록·원본 파일·수정 이력은 현재 브라우저에 저장됩니다. 방문 기록·사이트 데이터 삭제, 시크릿 모드 종료, 다른 브라우저나 주소로 접속하면 기존 기록이 보이지 않을 수 있습니다.
    JSON 백업은 원본과 수정 이력을 포함합니다. CSV는 표 형태로 확인하거나 기존 시트에서 가져올 때 사용합니다.
    
  
    
  
    
    
    GETTING STARTED
    사용 안내
    먼저 20~30건을 기록하며 자신만의 판단 기준을 만들어 보세요.
    
    
    기록 순서
    1. 결과를 보기 전에 새 기록을 엽니다. 캡처·PDF를 올리거나 직접 입력합니다.
    2. AI로 읽었다면 원본과 대조하고, 빠진 정보나 오독을 수정합니다.
    3. 예상 낙찰가·가상 입찰가·내 입찰 상한가를 구분해 작성합니다.
    4. 원본 대조와 결과 확인 전 예측 여부를 체크하고 저장합니다.
    5. 매각 후 목록의 ‘상세·복기’에서 실제 결과를 입력합니다. 최초 예측은 보존됩니다.
    6. 유찰 뒤 다음 기일은 ‘다음 기일 기록’으로 새 행을 만듭니다.
    어떤 자료를 올리면 좋을까요?
    물건 상세 화면 캡처가 법원·사건번호·매각기일·감정가·최저가를 함께 확인하기 좋습니다. 매각물건명세서와 등기부등본은 점유·권리관계 검토 자료로 함께 보관하세요. 이 문서만으로는 최저가와 다음 매각기일을 알 수 없는 경우가 있습니다.
    한 번에 같은 물건·같은 기일의 자료만 올려 주세요. AI는 법적 안전성이나 투자 수익을 확정하지 않습니다. 주요 판단은 원본을 확인해 별도 메모에 남겨 주세요.
    세 금액의 차이
    예상 낙찰가는 시장에서 낙찰될 것 같은 가격, 가상 입찰가는 내가 모의로 써낼 금액, 내 입찰 상한가는 예상 시세에서 비용과 목표 이익을 뺀 값입니다.
    성과 계산
    예측 오차율 = (예상 낙찰가 − 실제 낙찰가) ÷ 실제 낙찰가. 평균 절대 오차율로 정확도를 평가합니다. 결과 확인 전 예측, 유효한 작성일, 낙찰 결과와 가격이 있는 기록만 평가합니다. 오차 5% 이내는 경계값을 포함합니다.
    동액은 별도 표시합니다. 실제 낙찰 가능성과 수익성은 별개이며 이 기록장의 모의 비교로 확정할 수 없습니다.
    물건번호란?
    한 경매 사건에 여러 물건이 있을 때 구분하는 번호입니다. 사건번호가 같아도 물건번호가 다르면 별도로 기록합니다.
    기존 시트에서 옮기기
    Google 시트의 ‘마당 기록’ 탭에서 파일 → 다운로드 → 쉼표로 구분된 값(.csv)을 선택한 뒤 이 앱의 ‘가져오기’로 불러오세요. 파일명·원본 파일·Apps Script 변경 이력은 CSV에 포함되지 않습니다. 기존 시트도 보관하세요.
    내 기록은 어디 있나요?
    GitHub에는 프로그램 코드만 올라갑니다. 개인 기록은 이 브라우저에 있으며 자동 동기화되지 않습니다. 중요한 입력 뒤 ‘백업 저장’으로 JSON 파일을 내려받아 보관하세요. 브라우저 시계나 백업 파일을 직접 바꿀 수 있으므로 예측 시각을 외부에서 인증하는 도구는 아닙니다.
