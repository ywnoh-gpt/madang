| 등록된 키로 실제 Gemini 정상 작동 | 미확인 | 사용자가 전달한 응답은 HTTP 503이며 정상 연결·키 유효성을 증명하지 않음 |

브라우저 검증은 혼합 이미지/PDF → 인식값 수정 → 기존 개인 예측 유지 → 저장 → 결과 갱신 → 5% 오차 경계 집계 → 중복 거부를 확인했습니다. 320·390·1440px에서 페이지가 가로로 넘치지 않았습니다. 키 저장 테스트는 테스트용 문자열을 사용했으며 비밀번호 입력 칸이 비워지고 결과에 키가 노출되지 않는 것을 확인했습니다. 실제/모의 점검을 구분하고, 점검이 기존 기록·이력·Drive 보관 개수를 바꾸지 않는 것도 확인했습니다.

실제 키는 코드·GitHub·로그·보고서에 저장하지 않았습니다. 사용자가 Apps Script에 등록한 키를 여기서 읽거나 원격 실행한 것은 아닙니다. 모의 응답의 성공을 실제 API 성공으로 간주하지 않습니다. 앱의 **등록된 키로 실제 전체 점검**에서 API → PDF → 임시 시트 쓰기·읽기·삭제를 실행하고, 키를 제외한 진단 결과로 마지막 연동을 확인해야 합니다.

추가 검증은 503→정상 응답 복구, 최대 2회 재시도, 다른 오류 시 중단, 서버 대기 지시 준수, 정상 연결 전 키 유효성 미확인, 임시 시트 쓰기·읽기 불일치·정리 실패·이름 충돌의 실패 판정을 확인했습니다. 기존 실제 기록은 변경하지 않으며, 임시 탭만 만들고 정리하도록 검증했습니다.

Google 요청 기능의 권한·사용량·시간 초과·주소·보안 연결·잘못된 인수 예외를 분류하고 예외 상세에서 키·주소·이메일·긴 식별값을 가리는 것도 확인했습니다. 생성 요청은 시간 초과지만 모델 목록 조회는 성공하는 모의 상황에서도 전체 점검과 키 검증은 성공으로 표시하지 않았고, 실제 기록을 바꾸지 않았습니다. 이는 사용자가 보고한 현재 통신 오류의 실제 원인을 특정한 결과는 아닙니다. 해당 계정에서 최신 진단 결과를 실행해 확인해야 합니다.

재실행 명령은 [설치·개발 안내](google-sheets-app.md)에 있습니다. 코드가 바뀌면 이 결과를 그대로 최신 결과로 간주하지 말고 관련 검증을 다시 실행하세요.
