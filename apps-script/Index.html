읽기 어려운 표와 문구는 원본에서 확인하세요.

‘AI로 정보 읽기’를 누르면 선택한 자료가 Google Gemini API로 전송됩니다. 불필요한 개인정보는 가려 주세요. AI는 자료의 사실만 읽고, 나의 입찰 금액은 작성하지 않습니다.

원본과 한 번 더 확인해 주세요
    연결 설정 · 점검

    최초 실행의 ‘Google에서 확인하지 않은 앱’은 본인이 만든 프로젝트임을 확인한 뒤 고급 → 프로젝트로 이동 → 허용으로 승인합니다. API 키와 별도의 Google 계정 승인입니다.

    연결 상태를 확인해 주세요.

    키는 Google 스크립트 속성에 저장하고 화면에서는 지웁니다. 키를 저장해도 실제 API 연결 성공을 뜻하지는 않습니다.

    버튼마다 한 단계만 실행하며 자동 재시도하지 않습니다. 먼저 모델 목록 조회를 확인한 뒤 나머지를 각각 점검하세요. 요청 중에는 새 Gemini 요청을 추가하지 않습니다. 시간이 초과되면 마지막 점검 기록에서 중단 단계를 확인하세요. 시트 저장 점검은 API 호출 없이 임시 탭만 만들고 정리합니다.

    실제 테스트는 합성 PDF를 Gemini로 보내며 API 사용량이 발생할 수 있습니다. 모의 점검은 API를 호출하지 않습니다. 두 점검 모두 물건 기록에 테스트 행을 추가하지 않습니다.

      최초 시트 준비 후에는 같은 물건의 자료를 읽고 확인·수정하여 저장하세요. 다음 매각기일은 새 회차로 추가합니다.

      어떤 문서를 올리면 좋을까요?
      • 기본정보 화면 + 매각물건명세서로 시작하세요. 사건번호·매각기일·최저가를 함께 확인하기 좋습니다.
      • 감정평가서는 감정가·면적의 근거, 현황조사서는 점유 현황을 확인할 때 추가하세요.
      • 등기부등본은 등기 내용을 확인할 때 사용하세요. 주민등록번호 등 불필요한 개인정보는 가려 주세요.

      문서에 없는 가격·기일은 빈칸으로 남깁니다. HWP·Word는 PDF로 저장해 올리세요. 암호가 걸린 PDF는 해제 후 사용하세요. 서로 다른 물건·매각기일은 나누어 기록하고 권리관계는 원문으로 확인하세요.
