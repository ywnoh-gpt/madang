# 법인 수익 시뮬레이터의 계산 범위

이 모듈은 사용자가 확인한 세율과 비용을 넣는 거래 단위 검토용 현금흐름 모델입니다. 저장할 때 입력·계산 결과·버전·가정 메모를 함께 남깁니다. 기존 저장 결과는 수정하지 않으며 새 시나리오를 추가합니다.

## 확인해야 하는 가정

세율은 모두 **0%에서 시작**합니다. 취득세 본세, 지방교육세, 농어촌특별세, 취득·매각 건물 VAT, 공제 비율, 일반 법인세 증분 실효세율, 주택 추가세, 지방 법인세를 직접 입력합니다. 0% 그대로 저장할 때도 가정 확인과 근거 메모가 필요합니다. 유형 선택만으로 세율이나 저가 주택 예외를 추정하지 않습니다.

- 빌라 / 주거용 오피스텔: 직접 입력한 주택 추가세율과 과표 조정액을 적용합니다.
- 업무용 오피스텔: 주택 추가세를 0으로 계산합니다. 실제 사용 용도가 다르면 유형·가정을 바꿔 검토해야 합니다.
- 일반 법인세: 해당 거래의 양수 과세이익 × 사용자가 확인한 증분 실효세율. 법인 전체 과세표준·다른 소득·누진 구간·이월결손금·세액공제는 자동 반영하지 않습니다.
- 주택 추가 법인세: 주택 자산 양도이익에 별도 조정액을 더한 양수 과표 × 직접 입력한 추가세율. 운영비가 추가세 과표에서도 모두 공제된다고 가정하지 않습니다.
- 지방 법인세: 일반 법인세 × 입력한 비율. ‘추가세 포함’을 명시적으로 체크하면 추가세도 기초에 더합니다. 실제 신고 계산과 비율은 직접 검토하세요.

특정 연도의 법정세율 표나 자동 권리·용도 판정은 내장하지 않았습니다. 공식 법령·세무 검토 기준일을 메모하세요.

## VAT와 현금흐름

건물 비중 `s`, VAT 세율 `v`일 때, VAT 포함 금액의 공급가액 = 입력 금액 ÷ `(1+s×v)`입니다. VAT 별도 금액은 입력값 자체가 공급가액입니다. 건물 비중은 공급가액 중 VAT 과세 건물의 비중이며 토지는 이 모델에서 VAT 0으로 취급합니다.

1. 취득/매각 VAT = 각 공급가액 × 건물 비중 × 각 VAT 세율.
2. 취득 VAT 공제 = 취득 VAT × 공제 가능 비율.
3. 불공제 VAT = 취득 VAT − 공제. 불공제분은 자산 취득원가에 더합니다.
4. VAT 정산 = 매각 VAT − 취득 VAT 공제. 음수는 환급 가정입니다. 실제 환급 시기·요건은 모델 밖이며 그래프에서 음수로 표시합니다.
5. 취득세 등 = 취득 공급가액 × 입력한 본세/교육세/농특세 각각의 비율.
6. 취득원가 = 취득 공급가액 + 취득세 등 + 불공제 VAT + 자본적 지출.
7. 자산 양도이익 = 매각 공급가액 − 취득원가.
8. 일반 법인세 과세이익 = 자산 양도이익 − 운영비 − 매각 비용 − 금융 비용.
9. 순이익 = 매각 현금 유입 − 취득 현금 유출 − 취득세 등 − 운영비 − 자본적 지출 − 매각/금융 비용 − VAT 정산 − 일반/추가/지방 법인세.

각 세액과 공급가액은 원 단위 반올림한 검토값입니다. 손실에 대한 법인세 환급·다른 사업 소득과의 통산은 계산하지 않습니다. 운영비·자본적 지출·매각/금융 비용은 관련 VAT 공제와 과세상 조정을 반영한 최종 비용을 입력합니다. 이 항목의 VAT를 별도로 다시 공제하지 않습니다.

운영비는 당기 비용으로, 자본적 지출은 자산 취득원가로 구분해 과표를 계산합니다. 현금흐름에서는 각각 한 번만 차감합니다. 그래프는 세금과 순이익의 구성·음수 환급/손실을 보여주며 매각 대금 전체의 배분표가 아닙니다.
